### 执行摘要

GLP产品已验证我们的AI在高合规、非标场景下的工业级能力，积累了大量真实数据和客户信任。

**GCP产品线规划**以“从GLP案例建立信任 → 过渡到GCP标准重复线性部分”为战略，优先推出**Clinical Insights**（轻量级实时监控，像biotech的私人高级DM）和**IND Builder**（前期重点产品，标准明确、依赖客户少），快速形成收入闭环，再迭代到PV Report Pro、QA Guardian等日常高频产品，最终形成完整临床全链路平台。

**核心优势**：
- 复用GLP技术底座（LangGraph + 小模型集群 + Virtual SD），开发周期缩短60%。
- 层层递进定价：低门槛切入（Clinical Insights 20万/年） → 高价值升级（IND Builder） → 日常产品（PV/QA）。
- 预计2027年GCP收入占比达35%，与GLP形成“临床前+临床+申报”完整闭环。

本路线图分为**GCP产品规划多维度表格**、**定价体系**、**研发路线表格**三大部分。

### 2. 定价体系

**整体原则**：与GLP保持一致的层层递进模式，GCP产品定价略高于GLP（因临床数据更敏感、价值更高），Clinical Insights采用极低门槛定价。

| 产品 | 定价模式 | 建议价格（人民币/年） | 备注 |
|------|----------|-----------------------|------|
| **Clinical Insights** | 年订阅 | 20万 | 轻量级入门产品，biotech老板最易决策 |
| **IND Builder** | 按项目/年订阅 | 按项目：15-40万<br>年订阅：180-300万 | 前期重点产品，高价值 |
| **PV Report Pro** | 年订阅 + 按报告量 | 300-500万 + 按报告量 | 独立产品 |
| **QA Guardian** | 年订阅 | 400-600万 | 独立产品 |
| **RegDoc Enterprise** | 年订阅 + 私有部署费 | 1800万+（含专属LoRA） | 集团级，一次性部署费另议 |

**升级激励**：
- GLP客户升级GCP享20%折扣  
- Clinical Insights用户使用6个月后，赠送IND Builder 1个项目免费试用  
- 年度合同一次性签2年，享15%折扣
